# Firmware para ESP32

## Bancos de prueba

| Firmware | Controladores | Función |
|---|---|---|
| [01_rmp_actuator_test](01_rmp_actuator_test/) | ESP32-C3 Super Mini y ESP32-S3 SuperMini | Configuración web de pines, prueba de LED, botón, dos motores y hasta 16 sensores mediante CD74HC4067 |

Los firmwares de esta carpeta deben poder reutilizarse en distintos robots cambiando su configuración, sin depender del pinout definitivo de un proyecto.
