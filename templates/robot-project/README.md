# Plantilla de repositorio para un robot

Estructura recomendada:

```text
nombre-del-robot/
├── README.md
├── CHANGELOG.md
├── docs/
│   ├── ARQUITECTURA.md
│   └── CONEXIONES.md
├── firmware/
│   ├── pruebas/
│   └── robot/
├── hardware/
│   ├── esquematicos/
│   └── pcb/
├── cad/
├── bom/
├── telemetry/
└── images/
```

## README mínimo

- Objetivo y categoría.
- Estado actual.
- Fotografía o render.
- Hardware principal.
- Alimentación.
- Pinout.
- Estrategia de control.
- Instrucciones de uso.
- Enlaces a documentación detallada.

No todas las carpetas son obligatorias. Se deben crear solamente cuando haya contenido real.
