# Herramientas

Espacio para utilidades genéricas de RMP Robotics.

## Ejemplos

- Monitor serial y registrador CSV.
- Visor de telemetría Wi-Fi.
- Conversores o analizadores de registros.
- Scripts de compilación y empaquetado.
- Utilidades para calibración de sensores.
- Plantillas para interfaces de diagnóstico.

Toda herramienta debe indicar dependencias, sistema operativo probado, forma de ejecución y protocolo esperado.
