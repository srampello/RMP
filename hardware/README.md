# Hardware compartido

Espacio para referencias que se utilizan en más de un robot.

## Contenido recomendado

- Fichas resumidas de controladores y módulos.
- Comparativas de drivers de motores.
- Criterios de alimentación, masas y desacople.
- Referencias de conectores y cableado.
- Huellas verificadas que sean realmente reutilizables.
- Procedimientos de prueba eléctrica antes de conectar motores o baterías.

Los esquemáticos, PCB, medidas y BOM de un robot deben mantenerse en el repositorio de ese robot.
